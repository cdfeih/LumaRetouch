## 0.4.0：一键分析与专项修饰

新增智能自然／通透／保纹理三方案，单张和批量共用 `planAutomaticRetouch → renderAutomaticRetouch`。按整图和逐脸统计规划实际曝光、皮肤与光影参数，默认零塑形、零五官细节；人脸亮度和高光限制整体曝光，正 EV 会削减局部提亮，红绿范围存在时不做整图曝光。保纹理方案普通磨皮固定 0。可靠样本不足不修改该脸；模型失败不接受半成品。

本地统计不能可靠识别痘、痣、雀斑或理解夜景审美；公开平滑样片的实际变化很轻，不能据此宣称商业级精修。报告保留逐人实际参数、曝光和复核提示，支持手动微调、撤销和刷新。智能范围签名改变后从当前图建立新基准，同范围重复从固定底图计算，保护区／选区外保留现有效果。

新增八项云端专项模板，选择不发请求；点选或涂选后主动开始才调用云端，非专用模型。暂缓闭眼／表情重建、双眼皮、3D 塑颜与性别年龄分类，不用提示模板冒充专用能力。当前本地版仍没有全身肤色统一或独立毛发／衣物修复模型。

本轮 307 项单元测试与生产构建通过；真实 App 的重复处理、手动同参、撤销／重做、刷新、红 alpha1 与绿 alpha128 验收均通过。`tests/automatic-cancel.mjs` 另验证取消、指南互斥与迟到结果拒绝。

本轮验收入口：`tests/automatic-retouch.mjs`（真实本地模型与失败处理）、`tests/automatic-editor.mjs`（工作台重复／历史／草稿／画笔）、`tests/batch-automatic.mjs`（逐图规划、取消和恢复）、`tests/specialty-tasks.mjs`、`tests/editor-tools.mjs`（专项零请求选择及不规则选区合成）。真实付费云效果与 Android 真机仍未验证，具体安装包检查见 `release/LumaRetouch-0.4.0-manifest.json`。

## 历史：0.3.0 五轮实施记录

### 第一轮：先保护可逆性与结果

- 历史快照包含显示图、宽高、比较底图和对应人像参数／计算基准；撤销、重做、切图后继续调参沿用正确版本，减少旧底图覆盖新结果和重复累加。
- 每图分别保存红绿蒙版；切图与刷新恢复。生成后隐藏显示层，导出不包含标记。切换工具仍按工具语义清绿色范围；裁剪、旋转等坐标变化清双蒙版。
- 工作台自动草稿成功落盘才显示已保存；失败保留上次成功草稿。资源去重，限制为 256 MiB／250 个独立图片或蒙版，不默默丢弃历史来凑容量。
- 临时云端完整画面／选区切换对象不写草稿；已接受图像及可撤销历史写入。刷新不会重新消费云端调用。

### 第二轮：脸部 ROI 与本地语义皮肤

旧版把整幅图缩到 1600，远景小脸在工作图上只剩较少像素。现在按每张脸在原图裁出含滤波上下文的 ROI，每块最长边 1600；按脸顺序处理，原尺寸条带合成，避免每人创建整图大小的工作蒙版和差值。

新增本地 MediaPipe SelfieMulticlass 语义模型，使用 face-skin 类置信度并与关键点皮肤／五官区域相交，低置信度和类别竞争区域保守不改，避免把头发、衣物或遮挡误当皮肤。语义模型失败明确报错，不静默放宽保护；本地推理不上传照片，不识别身份。权重及 SDK 为 Apache 2.0，模型卡、许可与来源在 [public/models/README.md](../public/models/README.md)。

语义分割分辨率仍有限，保守排除可能使某些肤色和细节效果很弱；不是全身精确皮肤解析。嘴部、眼睛、侧脸、配饰和复杂遮挡仍需 100% 检查。大特写 ROI 会缩小，不能用“逐脸裁块”宣称原生全分辨率精修。

### 第三轮：批量先复核，再交付

- 先试一张、原图／结果与并排查看；可切 100% 并同步拖动两侧。
- 星标、待复核／已通过／需重修及筛选；重新处理结果回到待复核，成功成片状态保存在本地。
- 个人预设 JSON／文本导入导出，限定公开参数、128 KiB／20 项，重名编号、不覆盖旧参数、不夹带照片和密钥。
- ZIP 自动按 64 MiB 上限分包，逐包报告；取消／失败保留已交付部分并说明未完成数量，剩余结果仍在本地。单张超限需 JPEG 或缩小，不能靠分包拆一张图片。
- 仍是最多 100 张、每次从原始 File 串行计算，不是千张队列、后台续跑或逐图 AI 统一光色。刷新后只恢复成片，原图需再导入。

### 第四轮：RAW 基础和可控调色

独立 Worker 使用 @colorhythm/libraw-wasm 1.1.1 中的 LibRaw 0.22.1；实际运行 unpack／dcrawProcess，不走内嵌预览。完整对应 LibRaw C 源码与三份原始许可逐字节核对，采用 CDDL 1.0 分发独立库，MIT 绑定及依赖许可一并保留；生产 WASM 与 npm 原件 SHA 一致。见 [RAW 源码与分发说明](../public/raw/README.md)。

CC0 S9 24MP RW2 验收的原文件 SHA：
290ad5b4e396cb241a59459b2613d2b0659a03ff654e5d5368b3376d35812e50。26.4 MiB 输入经真实传感器解码输出 6016×4016、8bit sRGB PNG（约 48.5 MB）。开发 Chrome 约 6.5 秒、生产静态 HTTP 和隐藏 Electron file:// 沙盒约 5.3 秒，均不需要跨源隔离／SharedArrayBuffer，没有模型外网请求；这些时间只是当前设备单个样片观察。

八色 HSL、高光／阴影与 RGB 总曲线落在当前 8bit 编辑管线；裁剪、旋转与翻转回传新尺寸并可撤销。RAW 文件保留在用户原路径，草稿保存的是转档图；没有 RAW 域二次显影、16bit 全程或 ICC 保留，不能称作完整专业底片流程。

### 第五轮：局部点修和三种专项入口

本地点修在原尺寸的小区域内搜索或接收指定供样，匹配局部色彩并柔和拼接；不会重新生成五官。小痘点宜少量多次，复杂边缘、重复图案或光照不匹配可撤销后改供样。

一句话云端点修对绿色圆形范围发送照片与描述，红色保护优先、圈外本地保留。汗渍、衣服褶皱、整理碎发是可编辑提示模板，**不是专用模型已经训练或通过专业质量验收**。当前也没有自动任务规划、对话式批量助手或独立可排序图层。

## 推荐操作与保存范围

1. 导入代表照片，按需体检；用轻度人像参数，不先大幅塑形。
2. 100% 看皮肤、五官、衣领与背景；用小范围点修处理剩余局部问题，必要时调色和构图。
3. 人像参数保存预设，再批量先试一张；相同参数不代表不同光线下结果自动统一。
4. 抽查并标记成片，导出通过项；自动分包仍需要浏览器／系统允许连续下载或逐包保存。
5. 关闭前确认工程显示已自动保存；重要成片与原始 RAW 另行备份。

当前本地草稿能续修单张工作台，但不是通用工程交换或跨设备云同步。批量结果与原始 File 的保存范围不同；清理站点数据／卸载会删除本地记录。

## 历史：2026-10-20 中性灰光影实现与验收

Dodge & Burn 以选择性提亮／压暗修饰局部曝光；Adobe 官方也强调控制色调、颜色变化及裁剪。[Adobe 官方说明](https://helpx.adobe.com/photoshop/desktop/repair-retouch/adjust-light-tone/dodge-or-burn-image-areas.html)

本项目采用自行实现的有限支持多尺度三角核亮度分解、强边缘及蒙版孔洞屏障，生成最多 ±10 灰阶的平滑差值；不使用生成式重绘，也不是引导滤波论文或某商业软件的实现。AI 仅负责本地人脸定位。独立方案将光影设为 35%，清零其他肤色／细节项，保留已有塑形；直接操作光影滑块则允许与旧修饰组合。旧预设缺失该字段时补 0，不改变原有效果。

面部眼眉嘴之外，另对鼻部关键点凸包挖孔并向内羽化。红色保护区以最大覆盖缩放到计算网格，不参与光影邻域统计。原尺寸按人物及像素分别决定亮度限幅，避免另一人的调色设置解除该人物的保色限制；红区和绿区外仍硬保留。归零／更换方案从固定基准重算，旧肤色修饰也会按范围恢复。

数字验收同时要求斑块改善与细纹保留，避免空操作或单纯模糊过关：

- 236 项单元测试及生产构建通过，含 15 项光影分解测试，覆盖恒定／线性光照、强阶跃、孔洞／保护邻域隔离、不同方向／相位的 2～4 像素细纹，以及有斑块的纹理场。
- 新增 `tests/dodge-burn.mjs` 的 8 组真实浏览器验收通过。2400×1800 合成皮肤中，约 ±23.48 灰阶的斑块减至 ±18.48；斑块附近细纹对比约 8.00，处理前后比例约 1.00005，蒙版外、RGB 色差与透明度无变化。
- 公开人像验证眼眉鼻口与背景保留、红色 alpha=1 硬保护、重复不累加、归零、旧调色切换后清回基准、个人预设刷新及批量结果与单张一致。报告在 `artifacts/dodge-burn/report.json`，测试云请求、外网请求及渲染异常均为 0。

这些是受控图像与公开肖像的工程检查，不等于不同肤质、痘痕、侧脸或复杂光照下的专业品质认证。算法会减弱其处理中频范围的纹理；细纹测试并不表示所有空间尺度的皮肤细节完全不变。大块自然阴影刻意保留，严重瑕疵或复杂皱纹需要单独处理；小脸、强边缘和五官附近的效果可能很弱。工作图仍限 1600 像素，再将差值加回原片；不能从模糊原片恢复真实毛孔。Android 未做本轮真机验证，安装包未重新打包。
