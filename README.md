# 光修 AI · Luma Retouch

面向 Android、Windows 和本机浏览器的照片精修工具。当前源码 **0.4.0**：逐图智能一键修图、八项局部专项模板、本地人像精修／中性灰光影、RAW 基础转档、HSL／曲线调色、裁剪旋转、局部点修、工作台草稿恢复，以及最多 100 张的批量精修与分包导出。需要生成式创作时，可接入自己的图像模型 API。

## 版本与安装包

当前版本为 **0.4.0**，本地产物路径如下；实际大小、SHA-256 和验证范围见同版本 manifest：

- Windows 安装版：release/windows/LumaRetouch-0.4.0-x64-setup.exe
- Windows 便携版：release/windows/LumaRetouch-0.4.0-x64-portable.exe
- Android 预览版：release/android/LumaRetouch-0.4.0-debug.apk
- 源码／校验清单：release/LumaRetouch-0.4.0-source.zip、release/LumaRetouch-0.4.0-manifest.json

Git 仓库提交源码、模型与构建配置，不上传本地安装包。2026-10-19 的 **0.2.0 旧包没有本轮人像、批量、中性灰、RAW 与点修等新增能力**。界面显示版本，版本提示包含构建提交和 UTC 时间；dirty 表示构建时有未提交改动。

Windows 验收包含本地模型、RAW 解码、测试服务传输和保存；Android 验收范围为构建、签名与资源检查。**当前没有 Android 真机验收，也没有使用真实付费模型评估成片品质。** 每次发版实际验证范围以对应 manifest 为准。

## 第一次使用

1. 导入 JPEG／PNG／WebP：工作台最多 10 张，每张不超过 30 MiB／4000 万像素。RAW 限制见下文。
2. 先选「人像精修 → 一键智能修图」，按照片分析后在本机处理、无需 API Key。默认不自动塑形；可选自然保真、人像通透、保纹理精修，完成后可查看并微调逐人物参数。
3. 点「100%细节」检查眼眉、皮肤纹理与边缘；小瑕疵用「局部点修」。本地调色与「构图与旋转」均可撤销。
4. 一组照片点顶部「批量修图」（手机显示「批量」），先试 1 张再整组处理；需要创作、换天或添加内容时再配置云端模型。
5. 看到「工程已自动保存到本机」后可刷新续修；交付成片仍应导出 JPEG／PNG。Android 进入系统分享面板，Windows 使用保存对话框，浏览器触发下载。

左侧帮助和空白页提供四步指南。「照片体检」按需统计亮度直方图、近黑／近白比例与分辨率，可应用保守曝光建议；不理解夜景、逆光等创作意图，也不能找回过曝丢失的细节。

## 智能一键修图

「人像精修」顶部新增 **一键智能修图**，单张与批量共用同一条本地分析和渲染管线，不需要 API Key，也不上传照片。

1. 先分析整图亮度、阴影与高光，再检查人脸亮度，给出保守曝光；不根据暗背景盲目提亮已正常曝光的脸。有红色保护或绿色局部选区时关闭自动整图曝光。
2. 逐脸从原片 ROI 取样，结合关键点和语义皮肤范围，统计细纹、局部明暗差异、红点与油光，分别决定轻磨皮、中性灰光影、小红点减淡、肤色均匀、局部提亮、去油光及少量局部减红。**按需启用，不是每次七项全部执行**；样本不足的脸保留原样并提示。
3. 默认关闭全部脸部／身体塑形、黑眼圈、眼白、牙齿、唇色与整体肤色冷暖，不猜性别、年龄或理想肤色。结果显示实际曝光和每个人的参数，并同步到下方手动面板。

三个方案：**自然保真**适合轻修，**人像通透**在高光允许时适量提亮，**保纹理精修**关闭普通磨皮，以轻度光影修匀为主。可以选不同方案重新计算；同一底图与相同画笔范围重复运行不累加。红绿范围改变时，从当前画面建立新基准，避免覆盖已有修改；撤销、重做和草稿恢复会连同智能基准与报告保存。

下方「应用当前人像参数」（原「开始一键自然精修」）用于应用**当前手动参数**：首次默认磨皮 28、红点修饰 24、均匀肤色 20、肤色提亮 16、去油光 12，中性灰与其余参数为 0。它不会重新做逐图智能规划；用户主动开启的塑形或细节也会随当前参数应用。

这是保守的像素统计建议，不是审美大模型或专用痘／痣分类器。特殊妆容、舞台光、夜景及痣雀斑应在 100% 下复核；复杂瑕疵可以另用本地修补或云端专项。

## 本地人像精修

- 五组 **21 项参数**：自然精修、肤色调整、面部塑形、身体塑形、细节修饰。包括轻磨皮、小红点减淡、均匀肤色、美白、去油光、中性灰光影、冷暖／去黄／减红／红润、瘦脸／下颌／下巴、腰／手臂／腿／肩宽，以及黑眼圈、牙齿、眼白与唇色。
- 最多识别 10 人，可分别设置；缺失或不可靠的身体关节会限制对应塑形。修改参数后点击开始才处理，重复应用从固定底图重算，避免层层磨皮或不断变瘦。
- 从原片按脸裁取带上下文的 ROI，**每个脸部裁块最长边 1600**。小脸不再因为整幅大图缩小而继续损失计算像素；按脸串行、条带合成回原尺寸。大特写仍可能降采样，不等同于原生毛孔级精修。
- 本地 MediaPipe 六类语义分割与脸部关键点区域取交集，保守排除头发、衣物、背景和低置信度区域；五官孔洞、其他人物、红色保护与绿色选区继续约束结果。模型加载／推理失败会报错，不静默降级为不可靠的整脸修饰。见[模型来源、Apache 2.0 许可与模型卡](public/models/README.md)。
- 肤色主要处理可见面部皮肤，不是全身肤色匹配；小红点减淡仍是启发式算法。遮挡、小脸、侧脸和复杂光线可能识别不完整。
- 塑形采用本地几何变形与五官锚点，没有分层背景重建。背景直线可能随轮廓移动，宜小幅调整并用红笔保护栏杆、门框及其他人物。

「中性灰磨皮」保守方案将光影设为 35%、其他肤色与细节归零，保留已有塑形，再点击开始。建议从 20～40% 试起。它用多尺度亮度分解产生局部提亮／压暗差值并加回原片，不生成皮肤；不是专用商业中性灰网络、可编辑灰图层或 PSD。组合普通磨皮仍可能柔化纹理，不能从模糊原片恢复毛孔，也不能包办严重痘痕、皱纹和大面积阴影。

人物参数、识别与精修底图随照片切换恢复。撤销／重做恢复图像尺寸、比较底图与人像参数基准，避免回退后用错底图叠加；每张最多保留 5 步历史。其他工具改变图像时建立相应的新精修基准。

## 局部点修、调色与构图

| 点修方式 | 用途与边界 |
| --- | --- |
| 小瑕疵修补 | 在本地搜索附近纹理、匹配颜色并融合边缘；适合小痘点、斑点，非生成式，不重绘整脸。 |
| 指定供样修补 | 先点「设置供样点」再点目标；电脑支持 Alt 点击供样。纹理、方向与光线应接近目标。 |
| 一句话云端点修 | 支持点选圆形或涂选不规则范围，填写要求后调用所选模型；八项专项模板见下文，均非专用训练模型。 |

云端局部专项提供：手部肤色与小瑕疵、减淡颈纹、皮肤汗珠、衣物汗渍、衣物褶皱、整理碎发、局部纹身、局部体毛。每项包含建议范围、可修改的要求、复核方法和效果边界；选模板只准备要求与建议半径，**不会上传或计费**。先点选／涂选，再点击「开始云端点修」才调用所选模型，圈外本机保留，红色保护优先。它们是通用图像编辑的任务模板，不宣称具备八个专用模型。

闭眼／表情重建、双眼皮、3D 塑颜、性别年龄分类等尚未实现；不会在智能一键中自动修改这些特征。

先在 100% 用小半径逐处处理。红色保护优先；本地点修可能有重复纹理或接缝，不满意可撤销。云端可能改变圈内五官，圈外由本地合成保留。

本地调色有曝光、对比度、饱和度、蓝—琥珀／绿—洋红偏移、高光、阴影、红橙黄绿青蓝紫洋红八色 HSL，以及 RGB 总曲线。曲线可调黑场、暗调、中间调、亮调、白场，有柔和 S 曲线与重置。曝光按线性光缩放，后续控制基于 **8bit sRGB 编辑图**，不是 RAW 域或广色域工作流。

「构图与旋转」支持左右 90°、水平翻转、拖动裁剪与常见比例。原文件保留，可撤销恢复尺寸；因坐标改变，应用构图会清空红绿画笔范围，需重新涂选。

## RAW／松下 RW2 转档

单张工作台可导入 RW2、DNG、ARW、NEF、CR2／CR3、RAF 等 LibRaw 支持格式，单文件 **80 MiB**、解码图 **4000 万像素**以内。能否打开由机型、压缩和拍摄模式决定，不承诺所有同扩展名文件兼容；批量入口目前仍限 JPEG／PNG／WebP。

使用精确依赖 @colorhythm/libraw-wasm 1.1.1／LibRaw 0.22.1，在独立 Worker 中**解码传感器、去马赛克、使用相机白平衡并转为 8bit sRGB PNG**。不把内嵌 JPEG 预览冒充 RAW 解码；失败提示原因，不修改原始 RAW。草稿保留转档图，不包含原始 RW2 文件，请另行备份原片。

已用 raw.pixls.us 的 CC0 Panasonic DC-S9 24MP RW2 实测：26.4 MiB 输入、6016×4016 输出；开发浏览器、生产静态资源及 Electron file:// 沙盒均完成真实解码。PNG 约 48.5 MB，内存需要明显高于原文件；手机尚未验收，S9 48／96MP 等高像素模式不在当前范围内。转档色彩不保证等同于相机 JPEG、LUT 或厂商软件。

[RAW 许可与源码](public/raw/README.md)包含固定提交、WASM SHA 与完整对应 LibRaw 源码归档，随应用分发；Wrapper 为 MIT，LibRaw 选择 CDDL 1.0。当前没有 16bit 全流程、ICC／ProPhoto、HDR 底片或 RAW 域二次显影。

## 草稿、历史与画笔保存

工作台变更后自动存当前站点 IndexedDB，也可点「立即保存」。成功后在同一浏览器、同一地址刷新续修，可恢复当前／原始编辑图、活动照片、撤销与重做历史、尺寸／比较底图、人像参数／识别与计算基准，以及每张照片的绿色编辑与红色保护蒙版。

限制为 **256 MiB 图片与分割数据、250 份独立图像／蒙版资源、最多 10 张工作台照片**。共享图像去重，250 指资源版本数而非照片数。权限、空间或数量超限时保留上次成功草稿并显示错误；最新修改未必保存，请及时导出。尚未提交的描述、调色滑块等界面输入不属于完整工程交换格式。

云端添加内容的**临时完整画面／选区切换对象不恢复**；已接受当前图和历史会保存。刷新后不能继续切换同一次云返回的其他合成版本，也不会重调付费模型。

切换照片会恢复各自红绿范围；切换工具仍清除绿色选区，裁剪／旋转／翻转清除双蒙版。生成后自动隐藏标记、保留保护数据；眼睛按钮只隐藏，「清除」才删除范围，标记不烘焙进导出。

草稿、批量结果、预设和模型设置依赖当前站点／安装版数据目录。清理站点数据、卸载或换地址可能丢失记录；没有跨设备同步、工程文件交换或后台持续运行。

## 批量精修、复核与交付

列表最多 **100 张 JPEG／PNG／WebP**，每张 30 MiB／4000 万像素。串行按张读取、始终从原始 File 重算；无人脸说明后跳过，关键塑形部位不可靠会失败，不只套一半参数。支持取消、失败后继续与手动重试。

1. 默认「智能自然」，也可选「智能通透／智能保纹理」，每张原片分别分析、逐脸规划。手动自然保留、通透肤色、中性灰、当前单张参数及个人预设仍可选；智能结果可查看实际曝光和每脸参数。
2. 「先试 1 张」，原图／结果或并排对照，100% 原像素、同步拖动检查，再处理选中。
3. 用星标与「待复核／已通过／需重修」筛选成片；列表分页。重新生成回到待复核，已保存成片的复核和星标随结果恢复。
4. 单张下载或选中导出 JPEG／PNG ZIP，**自动按每包不超过 64 MiB 分包**。显示包序与交付张数，取消／失败说明已保存部分，其余成片留在本地。单张编码已超上限需改 JPEG 或缩小，不会静默漏图。浏览器可能需允许连续下载，Android 每包系统分享，Windows 每包选择保存位置。

批量不调用付费云端；统一参数应用各照片内识别人物，不做人脸身份匹配、不搬单张画笔或历史。不是按每张场景自动分析的组图统一，也不是千张后台队列。

成片 Blob、参数、警告和复核元数据落盘成功才显示完成。刷新可预览和导出已有成片；**原始 File 仅本次运行保留**，恢复后重新处理／原图对照需重新导入。删除记录也删本地结果，卸载前请导出。

个人预设最多 20 项，可命名保存、套用、更新、删除。在批量面板「预设导入与分享」可用 JSON 或文本复制／粘贴，文件最多 128 KiB，仅含名称与公开人像参数，无照片、人物信息或 Key。导入重名自动编号，超总量或字段无效整批拒绝，不覆盖旧预设；不兼容其他软件的专有预设。

## 云端创作与模型

已有磨皮、祛痘、去物、换天、去路人、添加内容、摄影／艺术风格、参考追色，另加一句话局部点修；都依赖用户选择的通用图像编辑模型。去物和云点修要求选区；添加内容可只写描述，自由安排布局。保护脸时先涂红，拥抱等互动可保护头部至颈部、让身体交叠位置可改。当前没有可排序的猫身体／前爪／人物独立图层，不能保证一次生成正确遮挡。

| 服务 | API 基础地址 | 初始模型 |
| --- | --- | --- |
| OpenAI | https://api.openai.com/v1 | gpt-image-2 |
| Google Gemini | https://generativelanguage.googleapis.com/v1 | gemini-3.1-flash-image |
| 火山方舟／豆包 | https://ark.cn-beijing.volces.com/api/v3 | doubao-seedream-4-0-250828 或图像模型接入点 |
| 兼容接口 | 按服务商填写 | 实际支持 /images/edits 与图片上传 |

默认型号仅方便填写，权限、地区和费用由服务商决定；聊天／仅识图模型不能输出修图。方舟完整 /images/generations 地址也会识别去重。Seedream 5.0 Flash 可填账号实际开通的型号或接入点。

OpenAI 使用原生透明蒙版；Gemini／方舟上传原图、可选参考图和黑白选区参考。模型可能误解，最终按本地蒙版／保护／强度合成。输入最长边 2048，原尺寸合成不代表恢复原片细节。磨皮、祛痘、追色、摄影风格按强度真实混合；添加、去物、换天、路人和艺术重绘完整显示生成内容，避免半透明残影。

红区 alpha＞0 保留本次处理前像素，外侧有限平滑过渡不能修复错误颈部。已检测且受保护的脸会检查位置、缩放、旋转与形变，不可靠时拒绝合成；未识别人脸或保护过少时检查不充分，不是身份识别。返回长宽比偏差超过 3% 也拒绝合成。

错误会分类显示、密钥脱敏并尽量保留 Request ID；不会自动重试付费调用。版权／内容拦截来自服务端，本地改提示不能解除。合同来源：[OpenAI](https://developers.openai.com/api/reference/resources/images/methods/edit)、[Gemini](https://ai.google.dev/gemini-api/docs/generate-content/image-generation)、[火山方舟](https://console.volcengine.com/ark/region:cn-beijing/docs/image-generation-api)。

## 数据、费用与质量边界

默认按「记住 API Key」把各服务 Key、地址、型号存浏览器 localStorage，明文本地保存，不写源码／不同步本项目服务器。取消记住删除本地 Key，本次会话可用；「清除密钥」同时清输入和本地记录。草稿与预设不含 Key。

只有点击运行云端功能才向所选服务商发送照片、参考图、蒙版和要求。本地人像、RAW、取样点修、体检、调色、构图、批量与导出不上传。取消拒绝迟到结果，但已提交任务仍可能计费；软件不附额度、不自动重试。

- 不承诺商业精修品质；语义、关键点和传统算法可能漏检／偏弱，先代表图试修、100% 复核再批量应用。
- 没有专用汗渍、衣发、天空、全身肤色或商业中性灰网络；提示模板不等于专用模型。
- 没有 16bit、专业 ICC、RAW 域二次显影、身份分类、独立可排序图层、跨设备协作与千张队列。导出不保留原 EXIF／ICC，拍摄方向在解码时处理。
- 本地模型使用公开照片做真实推理验收；云端主要验证合同／像素／受控响应，未测真实付费成片。Android 未做真机、大图内存和分享实测。

详情见[质量与工作流记录](docs/quality-and-workflow.md)。

## 源码结构

- src/App.tsx、src/editor/：工作台、版本化历史与 IndexedDB 草稿。
- src/imaging/、src/raw/：合成、色彩、几何与 RAW Worker。
- src/portrait/：人脸／身体／语义皮肤、ROI 修饰、塑形和预设。
- src/point-retouch/：本地取样修补。
- src/batch/：串行引擎、成片库、复核、预设交换与 ZIP 分包。
- src/components/：体检、色彩与构图。
- src/ai/、src/platform.ts：图像协议与跨平台传输／保存。
- electron/、android/、native/：原生外壳与本机开发代理。
- public/models/、public/raw/：模型、许可与 RAW 对应源码。
