# 光修 AI · Luma Retouch

面向 Android 与 Windows 的多模型照片精修工具。0.2 在磨皮、祛痘和涂抹去物的基础上，增加换天、去路人、添加内容、一键风格与参考图追色；当前源码另提供本地「人像精修」总入口，包含一键自然精修、肤色、面部与身体塑形、细节修饰、多人分别调整及个人预设。

## 可安装产物

Git 仓库只提交源码与构建配置。下列安装包是本地构建产物，不随代码上传；克隆后可按「本地开发」章节重新构建。

2026-10-19 早先构建的安装包如下；新增本地人像功能以当前源码运行或重新打包为准：

- `release/windows/LumaRetouch-0.2.0-x64-setup.exe`：Windows x64 安装版。
- `release/windows/LumaRetouch-0.2.0-x64-portable.exe`：Windows x64 便携版。
- `release/android/LumaRetouch-0.2.0-debug.apk`：Android 7.0 及以上的预览 APK，使用开发签名。
- `release/LumaRetouch-0.2.0-source.zip`：源码与构建配置，不包含依赖缓存。
- `release/LumaRetouch-0.2.0-manifest.json`：产物大小、SHA-256 与验证范围。

Windows 打包后的程序已验证导入、真实原生传输至本机测试服务、取消与保存照片。Android 已完成编译、签名及包内资源检查，尚未安装到安卓真机。所有模型测试均使用测试服务或受控响应，未验证真实付费模型的成片品质。

## 使用

1. 安装 Android APK（Android 7.0 及以上）或 Windows x64 安装包，也可以运行 Windows 便携版。
2. 导入 JPEG、PNG 或 WebP 照片。最多同时打开 10 张，每张不超过 30 MB／4000 万像素。
3. 默认进入「人像精修」下的「一键自然精修」，直接开始即可在本机识别人脸并修饰皮肤，无需 API Key。需要瘦脸、美白或身体调整时切换右侧分类。使用云端创作时，再到「模型设置」填写自己的 API Key、模型名称与地址。
4. 选择工具与预设；磨皮、祛痘、换天、去路人与风格可整图处理，也可以涂选局部。去物必须涂选目标；添加内容只需填写描述，绿色编辑选区可选；参考图追色必须上传样片。
5. 点击开始处理，检查前后对比；可撤销、重做，再导出 JPEG 或 PNG。

Android 导出通过系统分享面板保存或分享；Windows 导出使用文件保存对话框。关闭应用前请导出需要保留的结果，当前没有项目自动保存或跨设备同步。

## 已实现

- 1 个本地「人像精修」入口、5 个分类、20 项独立参数：自然精修、肤色调整、面部塑形、身体塑形与细节修饰。AI 在本机定位关键点，像素修饰与几何形变也在本机计算，照片不上传。
- 一键自然精修：轻磨皮、小红点修饰、肤色均匀、美白提亮与去油光，默认保持脸型与身材。
- 肤色调整：面部美白提亮、冷暖、去黄、减淡泛红与红润。「美白提亮」与自然精修中的「肤色提亮」共用一个参数。
- 面部塑形：瘦脸、下颌收窄与下巴长短，随脸部倾斜方向微调轮廓，固定眼眉、鼻子和嘴部的形状。
- 身体塑形：瘦腰、瘦手臂、瘦腿与肩宽微调，依据身体关键点及人物分割定位；关键点缺失或在画面外时禁用对应调整。
- 细节修饰：减淡黑眼圈、牙齿提亮、眼白提亮与唇色增强；通过局部区域及颜色过滤，避免漂白虹膜或改变五官几何形状。
- 多人分别调整：最多识别 10 人，可选所有人或单人，各人参数独立；未选人物的已识别脸部和身体、红色保护区及绿色选区外保留本次处理前像素。只做皮肤调整时，面部皮肤和主动开启的细节区域以外保持原样。
- 个人精修预设：命名保存、套用、同名更新与删除，最多 20 个，保存在当前浏览器。保存 20 项参数，兼容旧版五项自然精修预设，不保存照片、人物信息或 API Key。
- 8 个云端图像编辑工具：质感磨皮、祛痘、涂抹去物、智能换天、去路人、添加内容、一键风格、参考图追色。
- 5 种天空：晴空白云、金色日落、粉紫暮色、层云光隙、静谧星空。
- 6 种摄影调色：日系通透、夏日青绿、低饱和胶片、森系柔光、冷调街头、暖调电影，尽量保留摄影细节、人物身份与构图。
- 2 种艺术重绘：治愈手绘动画、清透水彩。治愈动画以手绘背景、柔软云朵与温暖自然光为方向，允许改变材质和笔触，不承诺复刻某位创作者的成片。
- 参考图追色将原图与样片一起传给模型，仅迁移色调与影调；一键风格也可上传参考图。色卡仅为氛围示意。
- 局部添加后可在「选区合成」和「模型完整画面」之间切换，检查物体是否超出选区而被裁断。切换使用同一次返回结果，不再次调用模型；完整画面的背景可能变化，可切回或撤销。此功能只保留更新后新生成的结果。
- OpenAI、Google Gemini、火山方舟／豆包，以及兼容 OpenAI 图像编辑合同的服务。
- 透明编辑蒙版与黑白选区参考图；结果按原照片尺寸合成，蒙版覆盖为零的区域保持原解码像素。
- 鼠标／触屏画笔、擦除选区、撤回涂抹、清除选区、前后对比分界、缩放。
- 独立保护画笔（快捷键 P）：手动涂满脸部或整个人，保护区优先于编辑选区，本次 AI 合成保留该区域处理前的原像素。添加内容切到完整画面时也保留当次保护快照。绿色为编辑区，红色为保护区；保护画笔可擦除、撤回或清空，切换照片后需重新涂选。
- 自由添加：不涂绿色选区时，AI 根据描述自主安排新增内容和遮挡关系；可以只用红色保护画笔锁住脸部等不希望变化的地方。未保护区域均可能变化。涂了绿色选区则仍限定局部，保护区始终优先；去物工具仍要求绿色选区。
- 最多 5 步编辑撤销／重做、多照片切换、JPEG／PNG 导出。
- 本地曝光、对比度、饱和度、蓝—琥珀和绿—洋红偏移；本地调色不调用云端模型。
- 原生 HTTP 传输、请求超时与取消、中文错误提示、密钥脱敏。

## 人像精修、人物与个人预设

导入照片后，左侧选择「人像精修」，右侧有「一键自然精修」「肤色调整」「面部塑形」「身体塑形」「细节修饰」五个分类。默认直接点击「开始一键自然精修」即可；其他分类点击「应用人像精修」，会一起应用所选人物当前的全部人像参数。

想只修合照里的某个人，先点「识别人像」，再点该人物缩略图，调整参数后开始。身体塑形先点「识别人像与身体」，定位腰、肩和四肢。切换人物会恢复各自的参数；选「所有人」时，修改某项会统一所有人的该项参数，其他项保留各人的设置。半身照没有可靠膝踝时不能瘦腿，双肩清晰时仍可微调肩宽；不要通过预设强行启用缺失的身体部位。

默认只开轻度自然精修；塑形、肤色附加项和五官细节全部为零。一般滑块范围为 0～100；肤色冷暖、下巴长短和肩宽支持 -100～100 的双向调整。「重置本组」「本组归零」只作用于当前分类；「恢复自然参数」「全部归零」作用于所选人物的全部参数。归零后再应用会恢复对应范围的本次精修基准，但红色保护区和绿色选区仍优先保留本次处理前像素。

参数修改或套用预设后，需点击开始才改动照片；重复应用始终从同一底图计算，不会层层磨皮或不断变瘦。局部精修后保留绿色选区，便于连续微调；可手动清除，切换工具或照片时仍会清空。其他工具改变照片后，会重新建立精修基准。原图对比、撤销与导出沿用现有操作。肤色调整目前只处理可见面部皮肤，不包含全身肤色匹配。

输入「预设名称」后保存即可下次套用；同名保存更新旧参数。多个人的参数不同时，先选一位人物再保存。刷新可恢复预设库，但照片与人物参数分配仍只在当前照片会话中。

检测模型及运行时随应用分发，见 [模型来源与许可证](public/models/README.md)。面部皮肤蒙版由关键点轮廓构造并排除眼眉嘴，并非完整语义皮肤分割；身体使用 Pose Landmarker 的关键点及人物分割。遮挡、小脸、侧脸及极端光线可能漏检，识别错误时可用红色画笔保护。轻微小红点处理是局部启发式修饰，不等同于专用语义祛痘模型；严重瑕疵可另用云端祛痘工具并检查结果。皮肤和细节计算工作图最长边 1600，再将差值合成回原尺寸，不能等同于原生高分辨率毛孔精修。

塑形采用局部几何变形，不调用云端重绘。轮廓附近的背景可能跟着移动，门框、栏杆和其他人物等可先用红色画笔保护，再从小幅度开始检查衔接。硬保护保持原像素，也会阻止该区域形变；本实现没有背景重建或分层补全，不能保证大幅度变形后的边缘自然。

## 模型配置

默认值只是方便填写，实际能否调用由服务商账号、地区和模型权限决定，名称和地址均可修改。普通聊天模型和只识图不输出图片的模型无法替代图像编辑模型。

| 服务 | API 基础地址 | 初始模型 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-image-2` |
| Google Gemini | `https://generativelanguage.googleapis.com/v1` | `gemini-3.1-flash-image` |
| 火山方舟 | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-seedream-4-0-250828`，也可填对应接入点 ID |
| 兼容图像编辑接口 | 按服务商文档填写 | 必须支持 `/images/edits` 和图片上传 |

OpenAI 使用原生透明蒙版，有参考图时使用多图上传。Gemini 与方舟依次上传原图、可选的风格参考图、可选的黑白选区图，提示词明确各图角色。最终由本地合成限制选区外的变化；模型未必完全理解复杂的选区指令。兼容接口需要支持相应的多图和蒙版合同。

方舟 API 地址建议填写 `https://ark.cn-beijing.volces.com/api/v3`。也兼容粘贴完整的 `/images/generations` 地址，软件会避免重复追加路径。Seedream 5.0 Flash 可使用官方型号 `doubao-seedream-5-0-flash-260915`，仍须由账号开通权限。HTTP 500 表示服务端内部异常，软件会保留当前照片且不自动重试；持续出现时，可凭服务提示中的 Request ID 向火山方舟排查。见[官方图片教程](https://console.volcengine.com/ark/region:cn-beijing/docs/seedream-5-0-pro)及[错误码](https://console.volcengine.com/ark/region:cn-beijing/docs/error-codes)。

官方合同来源：

- [OpenAI 图像编辑](https://developers.openai.com/api/reference/resources/images/methods/edit)
- [Gemini 原生图像生成与编辑](https://ai.google.dev/gemini-api/docs/generate-content/image-generation)
- [火山方舟图像生成](https://console.volcengine.com/ark/region:cn-beijing/docs/image-generation-api)

## 数据与费用

默认勾选「记住 API Key」，按服务商将密钥、模型地址与名称保存到当前浏览器的 localStorage，并恢复上次选择的服务商。同一浏览器、同一访问地址刷新或重新打开后会自动恢复；其他浏览器、地址或隐私窗口不共享。密钥以明文保存在浏览器本地，不会同步到本项目服务器或写入代码、配置文件。共用电脑可取消勾选：这会立即删除该服务商已保存的密钥，本次会话仍可使用；「清除密钥」会同时清空当前输入和本地密钥。浏览器禁止存储时会提示保存失败。照片与编辑记录仍仅保留于当前会话内。

仅在使用云端工具并点击「开始」后，才向所选服务商发送照片、选区、该工具使用的参考图与修图要求；人像精修的五类调整、人物检测、预设操作、导入、本地调色和导出不发送照片。云端调用按服务商规则计费，本项目不附带额度。取消会阻止软件继续接纳结果，但已提交的任务仍可能计费；软件不自动重试付费请求。

## 当前边界

- 云端 AI 使用最长边 2048 像素的输入；返回结果重采样至原图尺寸合成，不代表恢复原图全分辨率细节。精细的人像建议涂选处理。
- 换天、路人识别和追色使用所选通用图像编辑模型，没有单独训练的本地天空／人物分割器或专用追色模型；无选区整图生成可能改变细节。
- 通用模型整图输出可能改变眼睛、嘴部、衣服或人物位置；“保持五官不变”的文字要求不能代替像素保护。背景编辑建议从原图开始，先涂满人物保护区，再涂背景编辑区。保护区采用本次处理前的照片，不会自动修复此前已经被改过的脸；目前也不是自动人像分割。完整画面仍可能改变未保护区域。
- 拥抱等互动场景需允许合理遮挡：只保护脸、眼睛、头发，可不涂绿色选区、让 AI 按描述自主布局；需要精确定位时，再把动物身体及前爪覆盖衣物的位置纳入绿色编辑区。把整个人保护起来会阻止前爪出现在衣服前方。当前画笔是编辑／保护蒙版，不是可排序的独立猫身体、前爪、人物图层；模型仍可能生成错误的肢体或遮挡，不能保证一次成功。
- 不保证达到成熟商业软件的磨皮与追色品质。需检查五官、皮肤纹理、保留的人物和背景衔接。
- 模型返回画幅与原图长宽比偏差超过 3% 时会拒绝合成并保留当前照片，避免拉伸人物或错配选区。
- 暂不支持 RAW／RW2 解码、16 bit 工作流、专业色彩管理、自动批量修图、人脸分类、工程保存和跨设备同步。
- 导出以浏览器解码后的像素为基础，不保留原文件 EXIF／ICC 配置。EXIF 拍摄方向在解码时处理。
- 已做离线接口合同、像素与浏览器交互测试；没有使用真实付费 Key 验证成片效果。Android 构建成功也不等同于在你的手机上验证，需安装后检查系统版本、导入与导出。
- 桌面 Chrome 已通过 6000×4000、约 10.6 MB JPEG 的离线管线检查。大图合成后的 PNG 可能达到数十 MB，手机建议先一次处理一张；移动端大图内存仍需真机验证。

## 本地开发

需要 Node.js 22.14 或更高版本、pnpm 10、JDK 21。Android 构建还需要 Android SDK，脚本会优先查找已安装环境或专用工具缓存。

```powershell
pnpm install
pnpm dev
```

浏览器开发地址：`http://127.0.0.1:5178`。开发代理只接受本机同源请求；安装版通过原生 HTTP 请求避免浏览器跨域限制。

```powershell
pnpm build
pnpm test
node src/imaging/browser-smoke.mjs http://127.0.0.1:5178
node tests/integration.mjs
node tests/creative.mjs
node tests/ark-config.mjs
node tests/protection.mjs
node tests/free-add.mjs
node tests/portrait.mjs
node tests/portrait-studio.mjs
node tests/portrait-details.mjs
node tests/desktop.mjs
node --experimental-strip-types --test native/local-vision.test.ts
node --test electron/http.test.cjs
pnpm desktop:dev
# 打包windows版
pnpm desktop:dist
# 打包android版
pnpm android:apk
```

Windows 产物在 `release/windows/`。Android 产物位置以构建脚本输出为准。Android 预览版使用调试签名，正式发布前需由发行方配置长期保存的发布签名；当前没有上传应用商店或部署云端服务。

集成测试仅在测试脚本内拦截模型响应，拒绝所有外部请求，不会触发模型消费。它验证真实图片解码、蒙版与像素合成、撤销、导出、手机布局及关闭「记住 API Key」后的会话密钥行为；不验证模型实际修图品质。报告与截图在 `artifacts/integration/`，创作工具验收在 `artifacts/creative/`。`node tests/key-storage.mjs` 单独验证密钥刷新恢复、服务商隔离、取消记住与清除等浏览器本地保存行为。

`node tests/portrait.mjs` 用官方公开测试肖像和真实本地模型验证多人自然精修、五官与背景像素保留、预设重载及手机布局；`node tests/portrait-studio.mjs` 验证五分类入口、肤色与面部／身体塑形、重复应用、归零和扩展预设。`node tests/portrait-details.mjs` 逐项验证八种新增肤色和细节效果，使用 `LUMA_DETAIL_SCALE=2`（PowerShell：`$env:LUMA_DETAIL_SCALE='2'`）可覆盖超过 1600 像素工作图的缩放合成场景；报告在 `artifacts/portrait-details/`。`node src/portrait/render-smoke.mjs` 验证原自然精修 Worker、原尺寸合成、保护及取消。

## 源码结构

- `src/App.tsx`：修图工作台与会话状态。
- `src/imaging/`：图像解码、选区、像素合成、调色与导出。
- `src/portrait/`：本地人脸／身体检测、人像参数、皮肤与细节 Worker、局部几何塑形及个人预设。
- `src/ai/`：服务商图像编辑协议与请求测试。
- `src/platform.ts`：浏览器、Electron、Capacitor 的统一传输／导出接口。
- `electron/`：Windows 进程隔离、原生 HTTP 和保存对话框。
- `android/`：Android 工程及原生 HTTP 插件。
- `native/dev-proxy.ts`：仅本机开发使用的代理。
- `tests/`：浏览器集成验收。
